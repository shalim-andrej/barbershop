Двухстраничный сайт барбершопа: главная (услуги с ценами, мастера, работы, процесс, форма записи) и кейс клиента «один визит — весь образ» (до/после, решения, хронология по минутам, инструменты).

🌐 **Демо:** ссылка появится после деплоя · 📄 **[Страница кейса](case.html)**

> Демонстрационный проект для портфолио. Барбершоп, мастера, цены и отзывы вымышлены.
> Фотографии — визуализации, созданные нейросетью. Форма заявки в демо-режиме: данные никуда не отправляются.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Герой с фото и свободными окнами, цифры, 6 услуг с ценами и временем, 3 мастера, работы, 4 шага процесса, отзывы, форма записи |
| `case.html` | Кейс: факты (клиент, мастер, время, чек), фото до/после, задача, 4 решения, хронология визита по минутам, инструменты и средства, отзыв, призыв к действию |

## Стиль

- Палитра: графит `#161513`, латунь `#b08d57`, слоновая кость `#efe9df`
- Заголовки: Oswald, текст: Manrope — шрифты лежат локально в `assets/fonts` с кириллицей и не зависят от интернета
- Акценты: латунные линии, номера шагов, цены

## Что внутри проекта

- Адаптивный дизайн: десктоп, планшет, телефон, бургер-меню
- Появление блоков при прокрутке, с учётом настройки системы «меньше движение» (`prefers-reduced-motion`)
- Демо-форма с проверкой имени и телефона и понятным сообщением без отправки
- Sticky-шапка с затемнением, семантическая вёрстка

## Запуск

Никакой сборки не требуется — это статический сайт:

- **VS Code:** расширение Live Server → правый клик на `index.html` → *Open with Live Server*
- **Python:** `python -m http.server 8000` в папке проекта → откройте `http://localhost:8000`
- Или просто откройте `index.html` двойным кликом в браузере

## Деплой

Статический сайт: на [Vercel](https://vercel.com) — Framework Preset **Other**, Root Directory `./`, без сборки. GitHub Pages и Netlify тоже подойдут.
